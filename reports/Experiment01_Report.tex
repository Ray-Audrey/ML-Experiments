\section{Data Preprocessing}


The raw Iris dataset was prepared for machine learning using a series of preprocessing steps.

\begin{itemize}

\item \textbf{Missing Value Handling:}

The dataset was checked for missing values. No missing values were found, therefore no imputation technique was required.

\item \textbf{Encoding:}

The target variable ``Species'' contains categorical class labels. Label encoding was applied to convert the categorical species names into numerical class values suitable for machine learning algorithms.

\item \textbf{Feature Scaling:}

Standardization was performed using StandardScaler. The numerical features were transformed to have zero mean and unit variance. Feature scaling improves the performance of distance-based algorithms such as KNN and SVM.

\item \textbf{Train-Test Split:}

The dataset was divided into training and testing sets using an 80:20 ratio. Stratified splitting was applied to maintain equal class distribution in both training and testing datasets.

\item \textbf{Feature Selection:}

ANOVA based SelectKBest feature selection was applied. Since the Iris dataset contains only four meaningful features, all features were retained by setting $k=all$.

\end{itemize}

\section{Machine Learning Algorithms}

Four supervised classification algorithms were implemented and compared.

\subsection{Random Forest}

Random Forest is an ensemble learning algorithm that combines multiple decision trees to improve prediction accuracy. Each tree is trained using randomly selected samples and features, and the final prediction is obtained through majority voting.
\textbf{Mathematical Formulation:}

Suppose there are $N$ decision trees trained on different bootstrap samples of the dataset. The final prediction of the Random Forest classifier is obtained by majority voting:

\[
\hat{y}
=
\operatorname{mode}
\left\{
T_1(x), T_2(x), \ldots, T_N(x)
\right\}
\]

where $T_i(x)$ represents the prediction made by the $i^{th}$ decision tree.

\textbf{Advantages}

\begin{itemize}
\item Handles complex datasets effectively.
\item Reduces overfitting compared to individual decision trees.
\item Works well with numerical and categorical features.
\end{itemize}

\textbf{Limitations}:

\begin{itemize}
\item Requires higher computational resources.
\item Less interpretable compared to a single decision tree.
\end{itemize}


\subsection{Decision Tree}

Decision Tree classification uses a tree structure where data is split based on feature values to maximize class separation.

\textbf{Mathematical Formulation:}

Decision Trees split the data by maximizing information gain based on entropy.

\[
Entropy(S)
=
-
\sum_{i=1}^{c}
p_i
\log_2(p_i)
\]

where $p_i$ is the probability of class $i$.

\textbf{Advantages}

\begin{itemize}
\item Easy to interpret.
\item Requires minimal preprocessing.
\end{itemize}

\textbf{Limitations}:

\begin{itemize}
\item Can overfit small datasets.
\item Sensitive to small changes in data.
\end{itemize}


\subsection{K-Nearest Neighbors (KNN)}

KNN classifies a sample based on the majority class among its nearest neighboring samples.

The distance between samples is calculated using:

\[
d(x,y)=\sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}
\]

\textbf{Advantages}

\begin{itemize}
\item Simple implementation.
\item Effective for small datasets.
\end{itemize}

\textbf{Limitations}:

\begin{itemize}
\item Prediction time increases with dataset size.
\item Sensitive to feature scaling.
\end{itemize}


\subsection{Support Vector Machine (SVM)}

SVM finds an optimal hyperplane that separates different classes by maximizing the margin between support vectors.

\textbf{Mathematical Formulation:}

The separating hyperplane is represented as

\[
w^Tx+b=0
\]

where

\begin{itemize}
\item $w$ is the weight vector.
\item $b$ is the bias term.
\end{itemize}

The objective is to maximize the margin between the support vectors of different classes.

\textbf{Advantages}

\begin{itemize}
\item Effective in high dimensional spaces.
\item Provides good generalization.
\end{itemize}

\textbf{Limitations}:

\begin{itemize}
\item Parameter tuning is required.
\item Less suitable for very large datasets.
\end{itemize}

\section{Discussion}

This experiment successfully demonstrated the complete machine learning workflow using the Iris dataset, beginning with data loading and exploratory data analysis, followed by preprocessing, feature selection, model training, and performance evaluation. The exploratory analysis confirmed that the dataset is balanced, contains no missing values, and exhibits strong correlations between petal length and petal width, making these features highly informative for classification.

Standardization of the numerical features improved the performance of distance-based algorithms such as K-Nearest Neighbors and Support Vector Machine. ANOVA-based feature selection was also applied; however, all four features were retained because each contributed meaningful information to the classification task.

Among the evaluated models, Random Forest and Support Vector Machine achieved the highest classification accuracy of 96.67\%. The Support Vector Machine also produced the highest ROC--AUC score (0.9967), indicating superior discriminative capability. Decision Tree and KNN achieved an accuracy of 93.33\%, with only a few misclassifications occurring between the \textit{Iris-versicolor} and \textit{Iris-virginica} classes due to similarities in their feature distributions.

Overall, the experiment highlights the importance of proper preprocessing, feature selection, and model evaluation in building reliable machine learning models. Although the Iris dataset is relatively small and well-structured, the same workflow can be extended to larger and more complex datasets by incorporating techniques such as cross-validation, hyperparameter tuning, and ensemble learning.

\section{Conclusion}

This experiment provided practical experience in implementing a complete machine learning pipeline using Python libraries including NumPy, Pandas, Matplotlib, and Scikit-Learn. The workflow included dataset loading, exploratory data analysis, preprocessing, feature selection, model training, and performance evaluation using multiple supervised classification algorithms.

Four classification models—Random Forest, Decision Tree, K-Nearest Neighbors, and Support Vector Machine—were trained and compared on the Iris dataset. Random Forest and Support Vector Machine achieved the highest classification accuracy of 96.67\%, while the Support Vector Machine produced the highest ROC--AUC score of 0.9967, demonstrating excellent classification performance.

The experiment reinforced the significance of exploratory data analysis, preprocessing, appropriate feature selection, and quantitative performance evaluation in developing accurate and reliable machine learning models. The reusable implementation developed during this experiment also provides a scalable framework that can be applied to future machine learning tasks.
