\subsection{Linear Regression}


Linear Regression models the relationship between input features and the
target variable by fitting a linear equation.


The mathematical representation is:


\[
y = \beta_0+\beta_1x_1+\beta_2x_2+...+\beta_nx_n
\]


where:

\begin{itemize}

\item $y$ represents the predicted loan sanction amount.

\item $x_1,x_2,...,x_n$ represent input features.

\item $\beta_0$ represents the intercept.

\item $\beta_1,\beta_2,...,\beta_n$ represent feature coefficients.

\end{itemize}



The objective of Linear Regression is to minimize the residual sum of
squares:


\[
RSS=\sum_{i=1}^{n}(y_i-\hat{y_i})^2
\]


where $y_i$ is the actual value and $\hat{y_i}$ is the predicted value.




\textbf{Advantages}

\begin{itemize}

\item Simple and easy to interpret.

\item Computationally efficient.

\item Works well when relationships are approximately linear.

\end{itemize}



\textbf{Limitations}

\begin{itemize}

\item Sensitive to outliers.

\item Performs poorly with highly correlated features.

\item Cannot capture complex nonlinear relationships.

\end{itemize}





\subsection{Ridge Regression}


Ridge Regression is a regularized version of Linear Regression that reduces
model complexity by adding an L2 penalty term.


The objective function is:


\[
Loss =
\sum_{i=1}^{n}(y_i-\hat{y_i})^2
+
\lambda\sum_{j=1}^{m}\beta_j^2
\]


where:

\begin{itemize}

\item $\lambda$ is the regularization parameter.

\item $\beta_j$ represents model coefficients.

\end{itemize}



Ridge regression reduces large coefficient values and improves model
generalization.



\textbf{Advantages}

\begin{itemize}

\item Handles multicollinearity effectively.

\item Reduces overfitting.

\item Maintains all features in the model.

\end{itemize}



\textbf{Limitations}

\begin{itemize}

\item Does not perform feature selection.

\item Requires selection of suitable regularization parameter.

\end{itemize}





\subsection{Lasso Regression}


Lasso Regression applies L1 regularization by adding the absolute values of
coefficients as a penalty term.


The objective function is:


\[
Loss =
\sum_{i=1}^{n}(y_i-\hat{y_i})^2
+
\lambda\sum_{j=1}^{m}|\beta_j|
\]


The L1 penalty forces some coefficients to become exactly zero, which
performs automatic feature selection.



\textbf{Advantages}

\begin{itemize}

\item Performs feature selection.

\item Produces simpler models.

\item Reduces overfitting.

\end{itemize}



\textbf{Limitations}

\begin{itemize}

\item May remove important features when features are correlated.

\item Sensitive to regularization parameter selection.

\end{itemize}





\subsection{Elastic Net Regression}


Elastic Net combines both L1 and L2 regularization techniques.


The objective function is:


\[
Loss =
\sum_{i=1}^{n}(y_i-\hat{y_i})^2
+
\lambda
\left(
\alpha\sum|\beta_j|
+
(1-\alpha)\sum\beta_j^2
\right)
\]


where:

\begin{itemize}

\item $\alpha$ controls the contribution of L1 regularization.

\item $(1-\alpha)$ controls the contribution of L2 regularization.

\end{itemize}



Elastic Net provides the benefits of both Ridge and Lasso regression.



\textbf{Advantages}

\begin{itemize}

\item Handles correlated features better than Lasso.

\item Performs feature selection.

\item Reduces overfitting.

\end{itemize}



\textbf{Limitations}

\begin{itemize}

\item Requires tuning of multiple hyperparameters.

\item More computationally expensive.

\end{itemize}

\section{Performance Evaluation}


The trained regression models were evaluated using regression performance
metrics.


The following metrics were used:


\subsection{Mean Absolute Error (MAE)}


MAE measures the average absolute difference between actual and predicted
values.


\[
MAE=
\frac{1}{n}
\sum_{i=1}^{n}
|y_i-\hat{y_i}|
\]


Lower MAE indicates better prediction accuracy.




\subsection{Mean Squared Error (MSE)}


MSE calculates the average squared difference between actual and predicted
values.


\[
MSE=
\frac{1}{n}
\sum_{i=1}^{n}
(y_i-\hat{y_i})^2
\]


Lower MSE represents better model performance.




\subsection{Root Mean Squared Error (RMSE)}


RMSE is the square root of MSE and represents error in the same unit as the
target variable.


\[
RMSE=\sqrt{MSE}
\]




\subsection{R\texorpdfstring{$^2$}{2} Score}


R$^2$ score represents the proportion of variance explained by the model.


\[
R^2=
1-
\frac{
\sum(y_i-\hat{y_i})^2
}
{
\sum(y_i-\bar y)^2
}
\]


Higher R$^2$ indicates better model fitting.

Among all models, Lasso Regression achieved the best test performance with an R\textsuperscript{2} score of 0.6024. The results indicate that loan sanction amount depends mainly on loan request amount, property price, current loan expenses and credit score.

This experiment successfully implemented regression analysis using Linear Regression and regularized regression techniques.

The models were trained and evaluated using multiple performance metrics including MAE, MSE, RMSE and R\textsuperscript{2}. Hyperparameter tuning using GridSearchCV improved the selection of regularized models.

Lasso Regression achieved the best overall performance with the highest R\textsuperscript{2} score and lowest prediction error. The experiment demonstrates that regularization techniques improve model stability and reduce unnecessary feature influence while maintaining predictive accuracy.
